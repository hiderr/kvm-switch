# Матрица проверки клавиатуры 1.1.2

`python3 tests/run.py` компилирует фактический код приложения. Проверки
сопоставляют входные события, кадры TCP и события, подготовленные для macOS.
Вместо CGEvent.post используется запись событий в память: тесты не печатают
в пользовательские окна, не меняют громкость и не извлекают диски.

| Набор | Что проверяется |
| --- | --- |
| Виртуальные коды 0–127 | Код клавиши, нажатие, отпускание, тип клавиатуры, признак повтора |
| Буквы, цифры, знаки, ISO/JIS | Передача кодов без фильтра по раскладке |
| Return, Tab, Space, Escape, Backspace, Delete | Сбалансированные события |
| Стрелки, Home, End, Page Up/Down, Help | Сбалансированные события |
| F1–F20 и цифровой блок | Сохранение кода клавиши |
| Left/Right Command, Control, Shift, Option; Fn | Собственный код и бит каждой стороны, flagsChanged, отпускание |
| Caps Lock | Передача состояния без ложного «зажатия» и блокирования нового подключения |
| Специальные коды IOKit 0–23 кроме Power, а также 25 | Идентификатор, down/up/repeat, отпускание при завершении сессии |
| Хоткей переключения | Повторы и отпускание не попадают на второй Mac, включая смену настроек/разрыв связи |
| Разрыв связи и перехват физическим вводом | Освобождение нажатых клавиш и модификаторов |

Коды 0–127 покрывают стандартное пространство виртуальных клавиш macOS,
включая резервные позиции; это не перечень физических клавиш конкретной
клавиатуры. Модификаторы имеют тип flagsChanged, а не обычный keyDown/keyUp.

Отдельно требуется аппаратная проверка фактической клавиатурой: текст в нужной
раскладке, сочетания в конкретном приложении, системные действия и удержание.
Тесты передачи не доказывают, что конкретная версия macOS разрешит любое действие
в любом приложении. Touch ID/Power не отправляются; Secure Input не обходится.

## Результат 21.09.2026

На обоих Mac выполнены 1 028 регрессионных проверок (включая полный набор по TCP
loopback). Отдельный `LANKeyboard.swift`, собранный с фактическим Node, передал
446 событий через настоящую сеть в каждом направлении: 118 обычных кодов ×
нажатие/повтор/отпускание, 10 модификаторов × нажатие/отпускание, 24 специальных
кода × нажатие/повтор/отпускание. Принятые события совпали с отправленными по
полям и порядку, зажатых клавиш после завершения не осталось. LAN-прогон выполнен
до последней узкой поправки одновременного удержания двух изменённых хоткеев;
она отдельно покрыта шестью дополнительными регрессионными проверками.

Сборка LAN-пробы: `python3 tests/build_lan_keyboard.py /tmp/kvm-lan-keyboard`.
На принимающем Mac: `/tmp/kvm-lan-keyboard receive IP_ОТПРАВИТЕЛЯ /tmp/received.json`.
На отправляющем: `/tmp/kvm-lan-keyboard send IP_ПОЛУЧАТЕЛЯ /tmp/sent.json`.
Используется тестовый порт 53645; вывод — метаданные синтетических событий.
Реальная пользовательская клавиатура не перехватывается.
